# 十四论命门


雷真君曰：命门为十二经之主，《内经》已详言之。余再取而尚论者，盖命门之经虽彰，而命门之旨尚晦也。命门既为十二经之主，而所主者何主也？人非火不能生活。有此火，而后十二经始得其生化之机。命门者，先天之火也。此火无形，而居于水之中。天下有形之火，水之所克；无形之火，水之所生。火克于水者，有形之水也；火生于水者，无形之水也。然而无形之火，偏能生无形之水，故火不藏于火，而转藏于水也。命门之火，阳火也，一阳陷于二阴之间者也。人先生命门，而后生心，其可专重夫心乎！心得命门，而神明有主，始可以应物。肝得命门而谋虑，胆得命门而决断，胃得命门而能受纳，脾得命门而能转输，肺得命门而准节，大肠得命门而传导，小肠得命门而布化，肾得命门而作强，三焦得命门而决渎，膀胱得命门而收藏，无不借命门之火以温养之也。此火宜补而不宜泻，宜于水中以补火，尤宜于火中以补水，使火生于水，而还以藏于水也。倘日用寒凉以伐之，则命门之火微，又何能生养十二经耶！此《内经》所谓主不明则十二官危，非重言命门欤！

张真君曰：命门得天师之辨，正若日月之经天。今又得雷真君之尚论，则命门何至于晦而不彰乎！万世之大幸也。

（张景岳先生谓：善补阴者，宜于阳中补阴，无伐阳以散阴。善补阳者，宜于阴中补阳，无伐阴以救阳。深得此意。李子永识。）

---

### 一、命门为十二经之主

- **雷真君观点**：《内经》已言命门为十二经之主，然其旨尚晦。人非火不能生活，有此先天命门之火，而后十二经始得其生化之机。
- **命门火之特性**：
  - **无形之火**，居于肾水之中。
  - 有形之火（如薪火）为水所克；**无形之火**反为水所生。
  - 火不藏于火而**转藏于水**，即水中之火、龙雷之火。

---

### 二、十二脏腑皆赖命门温养

| 脏腑 | 得命门之火的作用 |
|------|------------------|
| **心** | 神明有主，始可应物 |
| **肝** | 谋虑 |
| **胆** | 决断 |
| **胃** | 受纳 |
| **脾** | 转输 |
| **肺** | 准节（治节） |
| **大肠** | 传导 |
| **小肠** | 布化 |
| **肾** | 作强 |
| **三焦** | 决渎 |
| **膀胱** | 收藏 |

- **结论**：十二经无不借命门之火以温养。人先生命门，而后生心，故不可专重夫心而轻命门。

---

### 三、治命门水火之法

- **雷真君治则**：
  - 命门之火**宜补而不宜泻**。
  - **宜于水中以补火**（如肾气丸之附、桂配六味），使火生于水而还藏于水。
  - **尤宜于火中以补水**（如重用熟地、山萸于温阳剂中），使水足而火不亢。
  - **大忌**：日用寒凉以伐之，则命门火微，十二经失养，即《内经》“主不明则十二官危”之意。

---

### 四、张真君评语

- 命门得天师之辨，正若日月经天。今又得雷真君之尚论，命门之旨大明，万世大幸。

---

### 五、李子永附识（张景岳阴阳互求说）

- 张景岳先生谓：
  - **善补阴者，宜于阳中补阴**，无伐阳以散阴。
  - **善补阳者，宜于阴中补阳**，无伐阴以救阳。
- 此深得雷真君“水中补火，火中补水”之旨。

---

### 六、小结

- “十四论命门”将命门学说推向新高度：命门为无形真火，藏于肾水，为十二经生化之本。治法以**水中补火（阴中求阳）**与**火中补水（阳中求阴）**为两大法门，与张景岳阴阳互济之说遥相呼应。此论为温补学派提供了坚实的理论基础，对肾命水火辨证具有提纲挈领的指导意义。
