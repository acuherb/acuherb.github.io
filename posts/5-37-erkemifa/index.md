# 岐真人传儿科秘法


山根之上有青筋直现者，乃肝热也，用柴胡三分，白芍一钱，当归五分，半夏三分，白术五分，茯苓一钱，山楂三粒，甘草一分，水煎服。有青筋横现者，亦肝热也，但直者风上行，横者风下行，亦用前方，多加柴胡二分，加麦芽一钱，干姜一分。有红筋直现者，乃心热也，亦用前方，加黄连一分，麦冬五分，去半夏，加桑白皮三分，天花粉二分。有红筋斜现者，亦心热也，亦用前方，加黄连二分。盖热极于胸中也，亦不可用半夏，用桑白皮、天花粉。有黄筋现于山根者，不必论横直，总皆脾胃之症，或水泻，或上吐，或下泻，或腹痛，或不思饮食。余定一方皆可服，服之无不神效。如皮黄，即黄筋也，方用白术五分，茯苓五分，陈皮二分，人参二分，神曲一分，麦芽二分，甘草一分，水一盅，煎半酒盏，分二起服，加淡竹叶七片。有痰，加半夏一分，或白芥子二分，或天花粉二分；有热，如口渴者是，加麦冬三分，黄芩一分；有寒者，加干姜一分；吐者，加白豆蔻一粒；泻者，加猪苓五分；腹痛者，如小儿自家捧腹是，须用手按之，大叫呼痛者，乃食积也，加大黄三分，枳实一分；如按之不痛，不呼号者，乃寒也，再加干姜三分。如身热者，不可用此方，予另立一方。

万全汤：凡小儿发热者，毋论夜热、早热、晚热，用之无不神效。方用柴胡五分，白芍一钱，当归五分，白术三分，茯苓二分，甘草一分，山楂三粒，黄芩三分，苏叶一分，麦冬一钱，神曲三分，水一盅，煎半酒盅服，或分二起服。冬天，加麻黄一分；夏天，加石膏三分；春天，加青蒿三分；秋天，加桔梗三分；有食，加枳壳三分；有痰，加白芥子三分；泻者，加猪苓一钱；吐者，加白豆蔻一粒。小儿诸症不过如此，万不可作惊风治之。有惊者，此方加人参五分，即定惊如神。有疳者，用脾胃方，加蒲黄三分，黄芩三分可也。

### 一、山根望诊法及分证用方

岐真人详述山根（鼻之上、眼之间）显现青、红、黄筋的辨证与主方：

#### 1. 山根青筋——肝热

- **直现**：肝热，风上行。  
- **横现**：肝热，风下行。

- **主方**（肝热通治方）：
  - 组成：柴胡三分，白芍一钱，当归五分，半夏三分，白术五分，茯苓一钱，山楂三粒，甘草一分。水煎服。
  - 加减：横现者（风下行）多加柴胡二分，加麦芽一钱、干姜一分。

---

#### 2. 山根红筋——心热

- **直现**：心热。  
- **斜现**：亦心热，热极于胸中。

- **主方**：
  - 用上方（肝热方）去半夏，加黄连一分、麦冬五分、桑白皮三分、天花粉二分。
  - 斜现者：加黄连二分，亦去半夏，用桑白皮、天花粉。

---

#### 3. 山根黄筋——脾胃病

- **特点**：不论横直，总属脾胃之症。症见水泻、吐、泻、腹痛、不思饮食、面黄等。

- **主方**（脾胃通治方）：
  - 组成：白术五分，茯苓五分，陈皮二分，人参二分，神曲一分，麦芽二分，甘草一分。加淡竹叶七片。水一钟，煎半酒盏，分二次服。

- **随症加减法**：

| 兼症 | 加味 |
|------|------|
| 有痰 | 加半夏一分，或白芥子二分，或天花粉二分 |
| 有热（口渴） | 加麦冬三分、黄芩一分 |
| 有寒 | 加干姜一分 |
| 吐 | 加白豆蔻一粒 |
| 泻 | 加猪苓五分 |
| 腹痛（手按之痛甚呼号，食积） | 加大黄三分、枳实一分 |
| 腹痛（按之不痛，寒） | 再加干姜三分 |

- **注意**：若身热者，不可用此方，当用万全汤。

### 二、万全汤——通治小儿发热

- **主治**：
  - 小儿诸般发热，无论夜热、早热、晚热，用之无不神效。不可作惊风治。

- **组成**：
