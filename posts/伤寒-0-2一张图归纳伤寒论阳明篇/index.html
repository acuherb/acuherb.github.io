一张图归纳伤寒论阳明篇

一、阳明病总纲与来路

  1. 阳明病分类（第194条）

    • 太阳阳明：发汗利小便亡津液，胃中燥，脾约便秘。
    • 正阳阳明：胃家实（胃肠实热积滞）。
    • 少阳阳明：利小便致胃中燥实，大便难。

  2. 阳明病提纲（第195条）

    • 定义：胃家实。

  3. 阳明病外证（第197条）

    • 身热、汗自出、不恶寒、反恶热。

  4. 转属阳明的来路（第196、200-204条）

    • 太阳病、少阳病误汗、误下、利小便亡津液，胃中干燥。
    • 太阳病汗出不彻，邪气入里。
    • 伤寒无汗呕不能食，后汗出濈濈然。
    • 太阴病小便自利、大便硬者转属阳明。
    • 阳明病典型体征：脉大，手足濈然汗出，恶寒自罢。

二、阳明病辨证要点

  1. 中风与中寒（第206-208条）

    • 阳明中风：能食（胃热消谷）。
    • 阳明中寒：不能食（胃中虚冷），手足濈然汗出，欲作固瘕，便初硬后溏。

  2. 寒热虚实鉴别

    • 胃中虚冷：不能食，攻热必哕，脉迟食难用饱，小便难（第210-211条）。
    • 久虚：身如虫行皮中状（第212条）。
    • 湿热发黄：无汗小便不利，心中懊憹，身必发黄（第215-216条）。
    • 热入血室：下血谵语，但头汗出（第234条）。

  3. 阳明病欲解时（第209条）

    • 从申至戌上（15-21时）。

三、阳明病治法核心——下法

（一）三承气汤证治

  1. 调胃承气汤（第223、263-264条）

    • 适应证：阳明病不吐不下心烦；太阳病发汗后蒸蒸发热（胃热未实）；吐后腹胀满。
    • 治法：和胃气，缓下热结。

  2. 小承气汤（第224、230-232、265-266条）

    • 适应证：阳明病腹大满不通；潮热、脉滑而虚；谵语便硬；燥屎未成或轻症。
    • 用法：微和胃气，勿令大泄下；若转矢气有燥屎可进，不转矢气不可攻。
    • 试探法：少与小承气汤，转矢气者可攻，不转矢气者不可攻（第225条）。

  3. 大承气汤（第224、229、232-233、253-257、267-271条）

    • 适应证：阳明病潮热、手足濈然汗出、大便已硬；谵语、燥屎已成；绕脐痛、烦躁发作有时；大便难、目中不了了（急下存阴）；腹满不减、减不足言；阳明少阳合病脉滑数有宿食；发汗不解腹满痛。
    • 急下证（第267-269条）：发热汗多、腹满痛、目中不了了（釜底抽薪，急下存阴）。

（二）下法禁忌

  1. 呕多不可攻（第220条）。
  2. 心下硬满不可攻（第221条）。
  3. 发热面赤不可攻，攻之发黄（第222条）。
  4. 表未解（微恶寒、脉浮无汗）先解表，后攻里（第224、234、250条）。
  5. 津液内竭便硬不可攻，宜蜜煎导、猪胆汁导（第248条）。
  6. 初硬后溏不可攻（第225、253条）。

四、阳明病表证及兼证

  1. 阳明病有表证（第249-250条）

    • 脉迟汗出恶寒：桂枝汤。
    • 脉浮无汗而喘：麻黄汤。

  2. 阳明兼少阳/太阳

    • 小柴胡汤（第245-247条）：发潮热大便溏胸胁满；胁下硬满不大便而呕舌上白苔；阳明中风脉弦浮大、胁下及心痛。
    • 白虎汤（第237条）：三阳合病，腹满身重口不仁面垢谵语，自汗出。

  3. 湿热发黄（第251、274-276条）

    • 茵陈蒿汤：瘀热在里，头汗出身无汗，小便不利，渴饮水浆。
    • 栀子柏皮汤：伤寒身黄发热。
    • 麻黄连翘赤小豆汤：伤寒身黄发热有表证。

  4. 胸膈热扰

    • 栀子豉汤（第240、244条）：心中懊憹、饥不能食、但头汗出。
    • 白虎加人参汤（第240条）：渴欲饮水、口干舌燥。
    • 猪苓汤（第240条）：脉浮发热、渴欲饮水、小便不利。禁忌：汗多胃燥者不可用（第241条）。

五、阳明病变证

  1. 蓄血证（第252、272条）

    • 抵当汤：其人善忘，大便硬而反易，色黑（久瘀血）。
    • 无表里证，发热脉数不解，大便难，为瘀血。

  2. 热入血室（第234条）

    • 下血谵语，但头汗出，刺期门。

  3. 谵语危候（第226-229条）

    • 直视谵语喘满者死，下利者死。
    • 脉短者死，脉自和者生。
    • 发不识人、循衣摸床、惕而不安：脉弦者生，脉涩者死。

  4. 脾约证（第262条）

    • 趺阳脉浮而涩，胃气强、小便数、大便难。
    • 麻子仁丸主之。

  5. 胃寒气逆（第258条）

    • 食谷欲呕属阳明，吴茱萸汤主之；得汤反剧属上焦。

六、治疗原则与禁忌

  1. 保护胃气津液

    • 不可妄汗妄下，防亡津液、胃中燥（第260-261条）。
    • 阳明病大便硬因津液内竭者，待自欲大便时导法通之（第248条）。

  2. 动态辨证

    • 观潮热、汗出、小便、转矢气判断燥屎形成与否（第224-225条）。
    • 先表后里，表解乃可攻里（第234条）。

  3. 整体调治

    • 寒湿发黄不可下，于寒湿中求之（第273条）。
    • 谷疸为胃虚寒，非湿热（第211条）。

八、核心思想

  • 本篇以“胃家实”为纲，系统构建了阳明燥热实证的辨证论治体系，尤其以三承气汤为核心，详辨燥屎形成与否、可攻与不可攻之指征，并严密设下禁忌，处处强调“存津液、保胃气”的治疗思想，同时涵盖阳明经表证、发黄、蓄血、脾约等兼变证的诊治。
