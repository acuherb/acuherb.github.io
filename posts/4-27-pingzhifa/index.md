# 平治法：论气虚、血虚、肾虚、胃虚、脾虚诸用药方


天师曰：平治者，平常之病，用平常之法也。气虚者，用六君子、四君子汤。血虚者，用四物汤。肾虚无火者，用八味汤；肾虚有火者，用六味地黄汤。肺虚者，用生脉散。心虚者，用归脾汤或天王补心丹。肝虚者，用建中汤。胃虚者，用四君子汤。脾虚者，用补中益气汤。郁症，用逍遥散。伤风，用小柴胡汤或参苏饮。有热者，用二黄汤。胃热甚者，用竹叶石膏汤。诸如此类，俱可以平常法治之，何必出奇眩异哉，此平治之宜知也。

---

### 一、平治法总纲

- **定义**：平治者，平常之病，用平常之法也。
- **治则**：针对临床最常见的气血阴阳虚损及外感轻症，选用历代验证的经典方剂，随证施治。

---

### 二、五脏虚证用方

| 虚证类型 | 推荐方剂 |
|----------|----------|
| **气虚** | 六君子汤、四君子汤 |
| **血虚** | 四物汤 |
| **肾虚无火**（肾阳虚） | 八味丸（肾气丸） |
| **肾虚有火**（肾阴虚） | 六味地黄丸 |
| **肺虚** | 生脉散 |
| **心虚** | 归脾汤或天王补心丹 |
| **肝虚** | 建中汤（小建中汤） |
| **胃虚** | 四君子汤 |
| **脾虚** | 补中益气汤 |

---

### 三、其他常见病用方

| 病症 | 推荐方剂 |
|------|----------|
| **郁症** | 逍遥散 |
| **伤风** | 小柴胡汤或参苏饮 |
| **有热** | 二黄汤 |
| **胃热甚** | 竹叶石膏汤 |

---

### 四、小结

- “平治法”体现了中医“**以平为期**”的治疗理念。对于临床最常见的虚证及外感轻症，历代医家已积累了成熟、安全、有效的方剂。医者当先熟练掌握这些“平平无奇”的基本方，辨证准确，随证化裁，自能取效。此与“奇治法”相对，一常一变，共同构成了中医完备的治疗体系。
