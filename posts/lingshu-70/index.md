# 寒热第七十


黄帝问于岐伯曰：寒热瘰疬在于颈腋者，皆何气使生？

> 黄帝问岐伯道：发冷、发热的瘰疬病，多发生在颈部和腋下，这是为什么呢？

岐伯曰：此皆鼠痿寒热之毒气也，留于脉而不去者也。

> 岐伯回答说：这是鼠瘘病的寒热毒气稽留在经脉，不能消除的结果。

黄帝曰：去之奈何？

> 黄帝问：这种病能否消除呢？

岐伯曰：鼠痿之本，皆在于脏，其末上出于颈腋之间，其浮于脉中，而未内着于肌肉，而外为脓血者，易去也。

> 岐伯答道：鼠瘘病本在于内脏，它所反映的症状，仅在颈部和腋部表现出来。如果毒气只在表浅的经脉中浮游，而没有停留在深部的肌肉而腐烂成脓血的，便容易治疗。

黄帝曰：去之奈何？

> 黄帝问：如何进行治疗呢？

岐伯曰：请从其本引其末，可使衰去，而绝其寒热。审按其道以予之，徐往徐来以去之，其小如麦者，一刺知，三刺而已。

> 岐伯答道：应从病的根源上着手治疗，以扶助正气，并通过治疗促使外在的瘰疬毒邪消散，以消除发冷发热的症状。同时，要明察发病的脏腑经脉，以便循经取穴，行针治疗。针刺时，慢慢地进针出针，达到扶正祛邪的目的。瘰疬初起，形小如麦粒者，针刺一次便能见效，针刺三次就可痊愈。

黄帝曰：决其生死奈何？

> 黄帝问：如何推断瘰疬病的预后呢？

岐伯曰：反其目视之，其中有赤脉，上下贯瞳子，见一脉，一岁死；见一脉半，一岁半死；见二脉，二岁死；见二脉半，二岁半死；见三脉，三岁而死。见赤脉不下贯瞳子，可治也。

> 岐伯答道：推断瘰疬病预后的方法是，翻开患者的眼睑进行观察，若眼中有红色的脉络，上下贯通瞳子，便是病情恶化的征兆。若出现一条红色的脉络，死期当在一年之内；出现一条半，死期为一年半之内；出现两条，死期为两年之内；出现两条半，死期为两年半；出现三条，死期为三年；若只有红色的脉络而没有贯通瞳子，尚能够治疗。

---

### 一、病因

- **病名**：寒热瘰疬（即鼠瘘），发于颈项、腋下。
- **病因**：由**鼠瘘寒热之毒气**（古称瘰疬为鼠瘘）留滞于经脉，日久不去而生。

### 二、病位与病机

| 病位层次 | 特点 | 治疗难易 |
| :--- | :--- | :--- |
| **本（根源）** | 在**五脏** | — |
| **末（标）** | 上出颈腋之间 | — |
| 毒气**浮于脉中**，未附着于肌肉，外溃为脓血 | 毒气尚浅，未内陷 | **易去** |

### 三、治法与疗效

- **治则**：**从其本引其末**（从根源引邪外出），使寒热毒气衰败而绝。
- **操作**：
  - 审察经脉通道后施针
  - 手法宜**徐往徐来**（缓慢进针出针）
- **预后**：
  - 瘰疬小如麦粒者：针刺**一次即见效**（一刺知）
  - 三次针刺即可痊愈（三刺而已）

### 四、死生预后的判断——察目诊法

通过观察眼中**赤脉**（赤色血络）贯穿瞳子的情况，判断死期：

| 赤脉数量 | 预后（死期） |
| :--- | :--- |
| **一脉**上下贯瞳子 | 一年后死 |
| **一脉半** | 一年半后死 |
| **二脉** | 二年后死 |
| **二脉半** | 二年半后死 |
| **三脉** | 三年后死 |

> **可治之征**：虽有赤脉，但**不下贯瞳子**（未贯穿瞳孔），可以治愈。
