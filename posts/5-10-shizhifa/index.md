# 失治法


天师曰：失治者，不能知病之真假、症之虚实与阴阳寒热，而妄治之也。信口雌黄，全无见识。喜攻人之短，炫自己之长。不识药味之温和，动言可用；何知方法之大小，辄曰难投。视熟地、人参为冤家仇敌；珍黄柏、知母为亲子娇儿。用寒凉之品，全无畏忌之心；见平补之施，顿作惊疑之色。喜攻喜散，矜消导为神奇；怒抑怒扬，薄通塞为怪诞。但明泻火，而不悟从治之妙，鄙茱萸为无用之材；仅晓益水，而不晓变症之方，笑甘遂为可弃之物。消痰而不消痰之本，诧病难攻；泻火而不泻火之原，叹方可废。奇平之法，原未曾熟究于胸中；正变之机，安能即悟于指下。无怪动手即错，背谬殊多，举意全非，失乱不少。以致冤鬼夜号，药柜中无非黑气；阴魂惨结，家堂上尽是啼声。愿学医者，见失以求得，庶可改过以延祥。然则求得延祥之法奈何？见寒药投之而拒格，即当改用大热之方；见热药投之而燥烦，即当改用清凉之剂；见消导之而转甚者，宜改温补；见祛邪之则更加者，宜用平调；见利水而水益多者，补肾为先；见散邪而邪益盛者，助正为急。此皆补过之文，抑亦立功之术，临症切须详审，慎弗忽略。

---

### 一、失治之由与常见误治

- **根源**：
  - 不能辨识病之真假、症之虚实、阴阳寒热，信口雌黄，全无见识。

- **常见误治表现**：
  - **畏补喜攻**：视熟地、人参为冤家，珍黄柏、知母为亲子。用寒凉全无畏忌，见平补顿作惊疑。
  - **矜炫己长**：喜攻喜散，矜消导为神奇；怒抑怒扬，薄通塞为怪诞。
  - **不明治法**：但明泻火而不悟从治（反佐）之妙，鄙吴茱萸为无用；仅晓益水而不晓变症之方，笑甘遂为可弃。
  - **舍本逐末**：消痰而不消痰之本，泻火而不泻火之原。

- **后果**：
  - 动手即错，背谬殊多，举意全非，以致冤鬼夜号，阴魂惨结。

### 二、求得延祥之法（误治后纠偏要诀）

天师详示临证纠偏之法则：

| 误治后反应 | 纠偏改法 |
|------------|----------|
| 见寒药投之而拒格 | 即当改用大热之方 |
| 见热药投之而燥烦 | 即当改用清凉之剂 |
| 见消导之而转甚者 | 宜改温补 |
| 见祛邪之则更加者 | 宜用平调 |
| 见利水而水益多者 | 补肾为先 |
| 见散邪而邪益盛者 | 助正为急 |

- **临证要诀**：
  - 此皆补过之文，抑亦立功之术。**临症切须详审，慎弗忽略**。

### 三、小结

- “失治法”从反面立论，剖析医者临证易犯之错误：畏补喜攻、不识反佐、舍本逐末、矜炫己长。天师更以药后反应为镜鉴，示人及时纠偏之道——寒热格拒者反其道而行，攻邪伤正者急改温补平调，利水反多者补肾为要。此节与“得治法”一正一反，共同构成了中医临证“知常达变、知失求得”的完整心法。
