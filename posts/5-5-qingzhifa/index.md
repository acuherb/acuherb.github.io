# 轻治法：论小柴胡汤


天师曰：轻者，病不重，不必重治，而用轻剂以治之也。如人咳嗽、头痛、眼目痛、口舌生疮，皆是小症，何必用重剂以补阳，用厚味以滋阴哉。法当用轻清之品，少少散之，无不立效，如小柴胡之方是也。然而小柴胡汤，世人不知轻重之法，予再酌定之，可永为式。方用柴胡一钱，黄芩一钱，半夏一钱，陈皮五分，甘草一钱，此小柴胡汤。予更加人参五分，茯苓二钱，更为奇妙。盖气足则邪易出，而汗易发。世人见用人参，便觉失色，匪独医者不敢用，即病者亦不敢服。相沿而不可救药者，滔滔皆是，安得布告天下医人，详察其病源，而善用之也。此轻治之法，极宜究心。

张公曰：天师言小柴胡汤，治外感者也。予言治内伤者，补中益气汤是也。然补中益气汤，东垣立方之后，世人乱用，殊失重轻之法。予再酌定之，可传之千古不敝。柴胡一钱，升麻四分，黄芪三钱，白术三钱，当归三钱，陈皮八分，甘草一钱，人参一钱，人气虚者多加，可至一两，看人之强弱分多寡耳。（〔批〕酌定补中益气汤。）若有痰，加半夏一钱；有热，加黄芩一钱；有寒，加桂枝一钱；头痛，加蔓荆子八分，或川芎一钱；两胁痛，加白芍三钱；少腹痛，亦加白芍三钱；有食，加麦芽二钱；伤肉食，加山楂二十粒；胸中痛，加枳壳五分，神曲五分。如此加用，自合病机。无如人不肯用此方以治内伤也，法最宜留心。大约右手寸口脉与关脉大于左手之脉者，急用此汤，无不神效。

（小柴胡本是半表半里少阳经药，内用参苓，以病在少阳，恐渐逼里，乘之于所胜也。故先扶胃气，使邪不入而已，入者亦得正旺而自退耳。李子永识。）

### 一、轻治法总纲

- **定义**：轻者，病不重，不必重治，而用轻剂以治之也。如咳嗽、头痛、眼目痛、口舌生疮等小症，何必用重剂补阳、浓味滋阴。
- **治则**：**轻清之品，少少散之**，无不立效。气足则邪易出，汗易发，故可稍佐参、苓扶正。

### 二、天师酌定小柴胡汤（治外感轻症）

#### **主治**：
- 外感初起，邪在少阳，寒热往来，头痛咳嗽，口苦咽干等轻症。

#### **组成**（天师酌定方）：
- 柴胡一钱，黄芩一钱，半夏一钱，陈皮五分，甘草一钱。更加**人参五分，茯苓二钱**，更为奇妙。
- 方解：
  - **柴胡**透达少阳半表之邪，**黄芩**清半里之热，**半夏、陈皮**和胃化痰，**甘草**和中。
  - 加**人参、茯苓**健脾益气，扶正以助祛邪。气足则邪易出，汗易发，且防邪气内传。

- **天师叹**：世人见用人参便觉失色，医者不敢用，病者不敢服，相沿成习而不可救药者滔滔皆是。当详察病源，善用人参。

- **李子永按**：小柴胡本治少阳半表半里，用参、苓乃因邪在少阳，恐渐逼里，先扶胃气使邪不入，已入者亦得正旺而自退。

### 三、张公酌定补中益气汤（治内伤不足）

#### **主治**：
- 内伤脾胃，气虚下陷，神疲乏力，食少懒言，头痛恶寒，脉右寸关大于左。

#### **组成**（酌定补中益气汤）：
- 柴胡一钱，升麻四分，黄芪三钱，白术三钱，当归三钱，陈皮八分，甘草一钱，人参一钱。**气虚者人参多加，可至一两**，看人之强弱分多寡。
- 方解：
  - **黄芪、人参、白术、甘草**补中益气，**当归**养血和营，**陈皮**理气和胃。
  - **升麻、柴胡**轻清升提，引清气上行，举下陷之阳。全方甘温除热，升阳举陷。

#### **随症加减法**：

| 症状 | 加味 |
|------|------|
| 有痰 | 加半夏一钱 |
| 有热 | 加黄芩一钱 |
| 有寒 | 加桂枝一钱 |
| 头痛 | 加蔓荆子八分，或川芎一钱 |
| 两胁痛 | 加白芍三钱 |
| 少腹痛 | 加白芍三钱 |
| 有食 | 加麦芽二钱 |
| 伤肉食 | 加山楂二十粒 |
| 胸中痛 | 加枳壳五分、神曲五分 |

#### **脉诊要诀**：
- **右手寸口脉与关脉大于左手之脉者**，急用此汤，无不神效。

### 四、小结

- “轻治法”以小柴胡汤治外感轻症、补中益气汤治内伤虚证为代表，强调**因证立法，以轻应轻**。天师于小柴胡中加参、苓，意在扶正达邪；张公酌定补中益气汤及加减法，示人治内伤须重脾胃、辨虚实。二方皆为轻剂典范，对临床常见病的平正调治具有重要指导意义。
