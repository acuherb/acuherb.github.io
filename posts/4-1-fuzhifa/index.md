# 富治法：论治膏粱宜补正气


天师曰：富治者，治膏粱富贵之人也。身披重裘，口食肥甘，其腠理必疏，脾胃必弱。一旦感中邪气，自当补正为先，不可以祛邪为急。若惟知推荡外邪，而不识急补正气，必至变生不测，每至丧亡，不可不慎也。方用人参三钱，白术三钱，甘草一钱，陈皮五分，茯苓三钱，半夏五分，为君主之药。倘有风邪，加入桂枝一钱，或柴胡一钱；伤暑，加入香薷一钱；伤湿，加入猪苓二钱；伤热，加入黄连一钱；伤燥，加入苏子一钱、麦冬五钱；伤气，加入白芍五钱；伤寒，加入肉桂一钱，水煎服。此方之妙，妙在健脾顺气，正补而邪自退。况又逐经各有加减妙法，使膏粱之子，永无屈死矣。此富贵之善治也。

张公曰：富贵治法，已备极细微，不必再行加减。

---

### 一、富治法总纲

- **定义**：富治者，治膏粱富贵之人也。
- **体质特点**：身被重裘，口食肥甘。其**腠理必疏，脾胃必弱**。卫外不固，运化无力。
- **治则**：感中邪气，**当补正为先，不可以祛邪为急**。若惟知推荡外邪而不识急补正气，必致变生不测。

---

### 二、主方及加减法

#### **基础方**（健脾顺气为主）：
- **组成**：人参三钱，白术三钱，甘草一钱，陈皮五分，茯苓三钱，半夏五分。水煎服。
- **方解**：此即**六君子汤**加减。以参、术、苓、草健脾益气，陈皮、半夏理气化痰。重在固护脾胃中气，使正气充则邪自退。

#### **随感邪加减法**：

| 所感邪气 | 加味 |
|----------|------|
| 有风邪 | 加桂枝一钱，或柴胡一钱 |
| 伤暑 | 加香薷一钱 |
| 伤湿 | 加猪苓二钱 |
| 伤热 | 加黄连一钱 |
| 伤燥 | 加苏子一钱、麦冬五钱 |
| 伤气 | 加白芍五钱 |
| 伤寒 | 加肉桂一钱 |

#### **精义**：
- 妙在健脾顺气，正补而邪自退。逐经各有加减妙法，使膏粱之子永无屈死。

### 四、小结

- “富治法”针对养尊处优者“腠疏脾弱”的体质特点，确立了**扶正为主、祛邪为辅**的治疗原则。以六君子汤为基本方固其中州，再据所感六淫之不同略加疏散清解之品，体现了中医“因人制宜”的辨证思想。此与“贫治法”相对，一补一攻，因体质而异，为后世体质学说在临床上的具体运用提供了范例。
