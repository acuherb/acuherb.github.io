# 王治法：论饮食难消 内伤诸症


天师曰：王治者，不可以伯道治之，而用王道治法为必全，而尊尚之也。如人病已将愈，不过饮食难消，胸膈不快，或吐酸，或溏泄，或夜卧不宁，或日间潮热，俱宜王道治之，而不可以偏师取胜。方用人参一钱，茯苓二钱，白术二钱，甘草五分，陈皮五分，半夏七分。此六君子汤也，最妙者。有热加黄芩三分；夜不睡加黄连五分，肉桂五分；潮热加柴胡一钱，地骨皮三钱，丹皮一钱；有食觉胸中少痛，加枳壳五分，山楂十粒；有痰加白芥子一钱；咳嗽加桔梗一钱；下泄水加车前一钱；腹中痛加肉桂五分，白芍一钱；头晕加蔓荆子一钱，川芎一钱；上吐酸水，加白芍三钱，倍加茯苓；饱满加枳壳五分。所谓王道荡荡，看之平常，用之奇妙，日计不足，岁计有余，何必用参至两计，加桂、附以出奇哉，此王道之法也。

张公曰：天师用药，多尚霸法，此偏以王道出奇，真不可测也。言医者，细心观之，勿以天师皆用霸术，而群以霸道斗奇，置王道于不用，又非天师之心，并失远公之求矣。

华君曰：未尝传予。

---

### 一、王治法总纲

- **定义**：不可以霸道（伯道）治之，而用王道治法为必全。王道者，平和中正，缓缓调治。
- **适用**：病已将愈，或内伤虚损，见饮食难消、胸膈不快、吐酸、溏泄、夜卧不宁、日间潮热等症。
- **治则**：健脾益气，和胃化痰，随症加减，不偏不倚。

---

### 二、基础方（六君子汤）

- **组成**：
  - 人参一钱，茯苓二钱，白术二钱，甘草五分，陈皮五分，半夏七分。水煎服。

- **方解**：
  - **人参、白术、茯苓、甘草**（四君子汤）——健脾益气，培补中焦。
  - **陈皮、半夏**——理气化痰，和胃降逆。
  - 六药合用，补而不滞，消而不伐，为调理脾胃虚弱、痰湿内停的基础方。

---

### 三、随症加减法

| 症状 | 加减药物 |
|------|----------|
| 有热 | 加黄芩三分 |
| 夜卧不睡 | 加黄连五分、肉桂五分（交泰心肾） |
| 潮热 | 加柴胡一钱、地骨皮三钱、丹皮一钱 |
| 食后胸中微痛 | 加枳壳五分、山楂十粒 |
| 有痰 | 加白芥子一钱 |
| 咳嗽 | 加桔梗一钱 |
| 下泄水样便 | 加车前子一钱 |
| 腹中痛 | 加肉桂五分、白芍一钱 |
| 头晕 | 加蔓荆子一钱、川芎一钱 |
| 上吐酸水 | 加白芍三钱，茯苓加倍 |
| 胸腹饱满 | 加枳壳五分 |

### 四、张公（仲景）按语

- 天师用药多尚霸道（峻猛直折），此处却以王道出奇，令人不可测度。
- 提醒后学：勿因天师多用霸术而群起效仿、以霸道斗奇，反置王道于不用。如此则失天师之心，亦违远公求道之本意。

---

### 五、小结

- “王治法”体现了中医“王道”调治的精髓。以六君子汤为基石，针对病后体虚、脾胃不和的种种变症，用药轻灵平和，随症损益，不求速效而功在长远。天师于此法中以王道示人，正说明霸道虽能攻坚，王道方为治本安身之正途。医者当霸则霸，当王则王，圆机活法，方为至境。
