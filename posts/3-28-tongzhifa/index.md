# 同治法：论四物、逍遥、六君、归脾、小柴胡、参苏、补中益气、四君子诸汤加减法。


天师曰：同治者，同是一方而同治数病也。如四物可治吐血，又可治下血；逍遥散可治木郁，又可治数郁；六君子汤可治饮食之伤，又可治痰气之积。然而方虽同，而用之轻重有别，加减有殊，未可执之以治一病，又即以治彼病耳。如吐血宜加麦冬、甘草，便血宜加地榆、黄芩之类于四物汤中也。如丹皮、栀子，宜加于木郁之中，黄连宜加火郁之中，黄芩、苏叶宜加于金郁之中，石膏、知母宜加于土郁之中，泽泻、猪苓宜加于水郁之中也。伤肉食，宜加山楂；伤米食，宜加麦芽、枳壳；伤面食，宜加萝卜子之类于六君子汤内也。同治之法，可不审乎。

张公曰：同治法不止三方，予再广之。归脾汤可治郁怒伤肝之人，又可治心虚不寐之症。小柴胡汤可治伤风初起之病，又可和伤寒已坏之病。参苏饮可治风邪之侵，又可治气郁之闷。补中益气汤可升提阳气，又可补益脾阴，兼且消食于初伤，祛邪于变后，疟症藉之以散邪，泻症资之以固脱也。四君子汤可以补气之不足，又可以泻火之有余，诸如此类，不可枚举，亦在人善悟之耳。

华君曰：余未传。

---

### 一、同治法总纲

- **定义**：同治者，同是一方而同治数病也。
- **治则**：同一方剂，针对不同病症，须在药量轻重、药味加减上精细斟酌，使方与证合。

---

### 二、天师所举三方加减法

#### 1. 四物汤（当归、川芎、白芍、熟地）

| 主治变通 | 加减法 |
|----------|--------|
| 吐血 | 加麦冬、甘草 |
| 便血 | 加地榆、黄芩 |

#### 2. 逍遥散（柴胡、当归、白芍、白术、茯苓、甘草、生姜、薄荷）

- **主治**：木郁（肝郁），亦可治诸郁。

- **五郁加减法**：

| 郁证类型 | 加味 |
|----------|------|
| 木郁 | 加丹皮、栀子（即丹栀逍遥散） |
| 火郁 | 加黄连 |
| 金郁（肺郁） | 加黄芩、苏叶 |
| 土郁（脾郁） | 加石膏、知母 |
| 水郁（肾郁） | 加泽泻、猪苓 |

#### 3. 六君子汤（人参、白术、茯苓、甘草、陈皮、半夏）

- **主治**：饮食所伤，痰气之积。

- **伤食加减法**：

| 伤食种类 | 加味 |
|----------|------|
| 伤肉食 | 加山楂 |
| 伤米食 | 加麦芽、枳壳 |
| 伤面食 | 加萝卜子 |

### 三、张公（仲景）广论五方通治

| 方剂 | 可治之症举例 |
|------|--------------|
| 归脾汤 | 郁怒伤肝之人，又可治心虚不寐之症 |
| 小柴胡汤 | 伤风初起之病，又可和伤寒已坏之病 |
| 参苏饮 | 风邪之侵，又可治气郁之闷 |
| 补中益气汤 | 升提阳气，补益脾阴，消食于初伤，祛邪于变后，疟症散邪，泻症固脱 |
| 四君子汤 | 补气之不足，又可泻火之有余 |

- **精义**：诸方应用广泛，在于**善悟其理，灵活化裁**，不可枚举。

---

### 四、小结

- “同治法”揭示了中医方剂学的精髓——**方有定体，用无定法**。一方通治多病，关键在于根据病机变化调整配伍与剂量。天师详示四物、逍遥、六君三方加减法度，张公更举归脾、小柴胡等五方通治之例，皆示人：**执方欲加之，须审证而变通**。此即“同病异治、异病同治”在方剂运用中的具体体现。
