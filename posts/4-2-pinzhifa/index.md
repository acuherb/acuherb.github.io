# 贫治法：论贫贱不可与富贵同治


天师曰：贫治者，藜藿之民，单寒之子，不可与富贵同为治法，故更立一门。盖贫贱之人，其筋骨过劳，腠理必密，所食者粗粝，无燔熬烹炙之味入于肠胃，则胃气健刚可知。若亦以富贵治法治之，未必相宜也。方用白术二钱，茯苓三钱，白芍三钱，甘草一钱，半夏一钱，陈皮五分，厚朴五分，共七味为主。有风者，加桂枝一钱，或柴胡一钱；有火者，加黄连一钱，或栀子一钱；有湿者，加猪苓二钱；有燥者，加麦冬五钱，苏叶一钱；有寒者，加肉桂一钱；有暑者，加香薷一钱；有热者，加石膏一钱；伤米食者，加麦芽二钱；伤肉食者，加山楂二十粒；伤面食者，加萝卜子一钱。以此方加减，无不神效。此贫贱治法，实有圆机，赖世医审之。

张公曰：贫贱治亦同，实无可传，非好隐也。

---

### 一、贫治法总纲

- **定义**：贫治者，藜藿之民，单寒之子，不可与富贵同为治法，故更立一门。
- **体质特点**：
  - 筋骨过劳，**腠理必密**——卫外较固，不易受邪，但邪入亦不易透达。
  - 所食粗粝，无膏粱厚味入于肠胃——**胃气健刚**，脾胃耐受力较强，不宜峻补壅滞。

---

### 二、基础方

- **组成**（七味基础方）：
  - 白术二钱，茯苓三钱，白芍三钱，甘草一钱，半夏一钱，陈皮五分，厚朴五分。水煎服。

- **方解**：
  - **白术、茯苓、甘草**健脾益气，运化中焦，助胃气以散邪。
  - **陈皮、半夏、厚朴**理气化湿，消导宽中，顺应粗食体质而防气机壅滞。
  - **白芍**敛阴和营，使散中有收，不伤正气。
  - 全方以**健脾理气、消导和中**为主，与富贵之人用六君子汤纯补不同，更侧重于“运”而非“补”。

---

### 三、随症加减法

| 所感病邪或兼症 | 加味 |
|----------------|------|
| 有风邪 | 加桂枝一钱，或柴胡一钱 |
| 有火 | 加黄连一钱，或栀子一钱 |
| 有湿 | 加猪苓二钱 |
| 有燥 | 加麦冬五钱、苏叶一钱 |
| 有寒 | 加肉桂一钱 |
| 有暑 | 加香薷一钱 |
| 有热 | 加石膏一钱 |
| 伤米食 | 加麦芽二钱 |
| 伤肉食 | 加山楂二十粒 |
| 伤面食 | 加萝卜子一钱 |

- **精义**：以此方加减，无不神效。其妙在顺应贫贱者腠密胃健的体质，以运脾理气为基础，随感邪之不同略加疏散清解消导之品，既不壅补，又不峻攻，实有圆机。

---

### 四、张公（仲景）评语

- 贫贱治亦同，实无可传，非好隐也。（意指贫治法理已明，无需赘言。）

---

### 五、小结

- “贫治法”与“富治法”相对，深刻体现了中医“**因人制宜**”的体质辨证思想。富贵之人腠疏脾弱，治宜补正为先；贫贱之人腠密胃健，治宜运脾理气、疏邪消导。一补一运，一静一动，全在识其体质根本。天师所立七味基础方及详备加减法，为临证治疗劳苦大众的常见病提供了精准的指导框架。
