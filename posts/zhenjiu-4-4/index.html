手阳明大肠经循行及穴位

循行

大肠手阳明之脉，起于大指次指之端，循指上廉，出合谷两骨之间，上入两筋之中，循臂上廉，入肘外廉，上臑外前廉，上肩，出髃骨之前廉，上出于柱骨之会上，下入缺盆，络肺，下膈，属大肠。其支者，从缺盆上颈，贯颊，入下齿中；还出挟口，交人中，左之右，右之左，上挟鼻孔。

穴位

手阳明穴起商阳，二间三间合谷藏。

阳溪偏历温溜济，下廉上廉三里长。

曲池肘髎迎五里，臂臑肩髃巨骨起。

天鼎扶突禾髎接，终以迎香二十止。

一、大肠经总论

1. 大肠经的核心定位

  • 肺与大肠相表里：肺主气、主皮毛；大肠主传导、主津液再吸收。二者一肺一腑，共同调节气机与水液。
  • 阳明多气多血：手阳明大肠经气血充盛，手部轻触即易动气，临床反应较灵敏。
  • 卯时流注：大肠经气血流注于卯时（5:00—7:00）。顺时针揉丹田可助排便，可作为时辰养生线索。
  • 肺与大肠的水气关系：

吸气为肾主，吐气为肺主；小肠火助大肠气化，热气上升，肺形成津液。

  • 五输属性：阳经五输为 井金、荥水、输木、经火、合土。

2. 五行与补泻抓手

项目内容
所属脏腑大肠，属金
表里经肺经
五输商阳（井金）、二间（荥水）、三间（输木）、阳溪（经火）、曲池（合土）
母穴曲池（土生金）
子穴二间（金生水）
原穴合谷
络穴偏历
郄穴温溜

记忆：虚补曲池，实泻二间；原络合谷、偏历；急症郄穴温溜。

按商阳 → 迎香排列；标有“核心”的穴位为优先掌握对象。

1商阳食指桡侧指甲角井穴放血、退热核心
2二间食指掌指关节前荥水、泻实热常用
3三间食指掌指关节后手不能握、风湿常用
4合谷手背第1、2掌骨间原穴、面口总穴核心

核心穴提示：商阳、合谷、阳溪、手三里、曲池、肩髃、迎香。

三、按循行分段精讲

1. 手腕段：商阳 → 阳溪

这一段从指端走到腕部，是退热、咽痛、手部病与面口病的第一线。

穴位定位属性主治方向操作要点
商阳食指桡侧指甲角旁井穴，属金高热、咽喉肿痛、扁桃腺炎点刺放血
二间第2掌指关节前桡侧荥穴，属水急性疼痛、热证子穴，泻实
三间第2掌指关节后桡侧输穴，属木风湿关节痛、手不能握可透劳宫或合谷
合谷手背第1、2掌骨间原穴面口病、皮肤瘙痒、牙痛孕妇慎针
阳溪腕背横纹桡侧经穴，属火往来寒热、腕痛临床较少用

【核心】商阳

  • 定位：食指桡侧指甲角旁。
  • 重点理由：大肠经井穴，指端泄热最快的穴位之一。
  • 主治抓手：发热、咽喉肿痛、扁桃腺炎、热证。
  • 常用配伍：少商 + 商阳 + 大椎，用于热病退热思路。

【核心】合谷

  • 定位：手背第1、2掌骨之间，约平第2掌骨桡侧中点。
  • 重点理由：大肠经原穴，四总穴之一，“面口合谷收”。
  • 主治抓手：牙痛、面肿、口眼歪斜、鼻病、皮肤瘙痒、青春痘。
  • 原络配穴：合谷配列缺，原络相应，用于肺与大肠虚实夹杂。
  • 四关穴：合谷配太冲，用于全身不适、疼痛部位不清时的诊断与通络。
  • 注意：孕妇慎用；“可泻不可补”，临床非专业人士不要自行操作。

合谷是临床高频穴，但孕妇、体弱者及特殊人群须严格慎用。

【核心】阳溪

  • 定位：腕背横纹桡侧，拇指上翘时出现的凹陷处。
  • 重点理由：大肠经经穴，属火，可用于往来寒热一类表证。
  • 主治抓手：寒热往来、腕臂痛、头痛、目痛。
  • 操作要点：临床使用频率不如合谷、曲池，但作为五输体系的一环必须记住。

2. 前臂段：偏历 → 手三里

这一段偏重络穴平衡、郄穴急症、前臂局部与扭伤疼痛。

穴位定位属性/要点主治方向
偏历腕后3寸络穴耳鸣、牙痛、肩痛、肺大肠表里失衡
温溜腕后5寸郄穴大肠经急性发炎、肿痛、热毒
下廉前臂背面桡侧局部穴手臂痛、乳痈
上廉前臂背面桡侧局部穴手臂痛、乳痈
手三里肘横纹下2寸扭伤要穴落枕、扭伤、手臂痛

【常用】偏历

  • 定位：前臂背面桡侧，腕横纹上3寸。
  • 重点理由：大肠经络穴，与肺经络穴列缺相表里。
  • 主治抓手：耳鸣、牙痛、鼻出血、肩臂痛。
  • 配伍思路：与列缺配合，调和肺与大肠表里经气。

【常用】温溜

  • 定位：腕横纹上5寸，偏历上2寸。
  • 重点理由：大肠经郄穴，主急症、疼痛与热毒。
  • 主治抓手：急性肿痛、咽喉肿痛、肠腹痛、热病。
  • 取穴要点：可在骨缝处进针。

【核心】手三里

  • 定位：肘横纹下2寸，前臂背面桡侧。
  • 重点理由：“扭伤穴”，对落枕、扭伤疼痛恢复常用。
  • 主治抓手：落枕、肩臂痛、肘臂扭伤、腹痛。
  • 操作要点：急症时可配合远端取穴与局部压痛反应。

3. 肘肩段：曲池 → 肩髃

这一段是皮肤、肩臂、中风与肘部疼痛的常用区。

穴位定位主治方向操作要点
曲池屈肘横纹外端皮肤病、肩痛、虚证母穴，可补
肘髎肘外侧网球肘、肘臂痛可放血、拔罐
手五里肘上3寸臂痛、瘰疬有大动脉，禁针
臂臑肩髃下2寸瘰疬、臂痛可针可灸
肩髃肩峰前下方肩痛、中风、狐臭可透极泉

【核心】曲池

  • 定位：屈肘，肘横纹外端与肱骨外上髁连线中点。
  • 重点理由：大肠经合穴，属土，为大肠经母穴；善于扶正、清皮肤与阳明经热。
  • 主治抓手：皮肤病、瘙痒、肩臂痛、发热、肘痛。
  • 常用配伍：配合谷止痒最速；配血海治皮肤瘙痒。
  • 手法补充：曲池、二间不适合迎随法，可用捻转法，补五泻六。

【核心】肩髃

  • 定位：肩峰前下方凹陷处。
  • 重点理由：中风八大穴之一，肩部局部病要穴。
  • 主治抓手：肩痛、肩关节不利、中风上肢不遂。
  • 操作要点：近取肩病效佳；有“透极泉”治狐臭的经验。

4. 颈项段：巨骨 → 扶突

这一段穴少但位置敏感，重在颈项、咽喉与局部触诊判断。

穴位定位主治方向操作要点
巨骨锁骨肩峰端与肩胛冈之间肩臂屈伸不利靠近肺尖，慎针
天鼎胸锁乳突肌后缘咽喉、颈项、肿物诊察有动脉，慎针
扶突喉结旁3寸咽喉肿痛、咳嗽、气喘慎针

颈侧肿瘤位置可作经络辨证参考——外侧属大肠经，内侧属胃经。

5. 面鼻段：口禾髎 → 迎香

这一段是鼻部疾病的终点区。

穴位定位主治方向操作要点
口禾髎鼻翼下缘，口唇上鼻塞、鼻窦炎、鼻出血局部取穴
迎香鼻翼外缘中点旁嗅觉障碍、鼻塞、鼻窦炎可透内迎香，慎针

【核心】迎香

  • 定位：鼻翼外缘中点旁，鼻唇沟中。
  • 重点理由：大肠经终点穴，鼻部局部取穴核心。
  • 主治抓手：鼻塞、鼻炎、鼻窦炎、嗅觉减退。
  • 常用配伍：配合对侧合谷；也可向上星、素髎方向形成鼻病取穴组合。
  • 注意：慎灸、慎透针，避免伤及眼眶与骨膜。

四、补泻法则与虚实判断

1. 虚实判断时间轴

表现辨证处理原则
痛在1周内偏实泻法为主
痛多酸少实中带虚先泻后补
酸多痛少虚中带实先补后泻
仅酸无痛纯虚补法

2. 针法关键

  • 顺经为补，逆经为泻。
  • 捻转法：快进慢出，防止卡针。
  • 插提法、迎随法：依据部位、疼痛强度与虚实决定。
  • 曲池、二间：不适合迎随法，改用捻转法，补五泻六。

五、诊断与经验补充

  • 小儿三关：风关、气关、命关观察青筋，用于判断病势深浅。
  • 合谷诊虚实：“合谷大气足，陷表示虚”，可作气血盈亏望诊线索。
  • 大肠经皮肤反应：手臂大肠经循行处出现压痛、结节或热感，可提示本经气机变化。
  • 卯时排便：卯时大肠经气血旺，顺时针揉丹田有助于排便，可作为生活调养小法。

大肠经取穴口诀

商阳退热少商同，二间泻实三间风；
合谷面口四关主，阳溪寒热腕间逢；
偏历温溜络郄别，手三里扭落枕功；
曲池肩膀清皮肤，肩髃中风臂不充；
天鼎扶突颈侧慎，禾髎迎香鼻窍通。

八、小结

大肠经二十穴，从商阳到迎香，主线是“指端泄热、前臂调络、肘肩清阳明、颈鼻开清窍”。
先抓商阳、合谷、阳溪、手三里、曲池、肩髃、迎香七穴，再用五输、原络、郄穴把其余穴位串起来，大肠经的取穴体系就清楚了。
