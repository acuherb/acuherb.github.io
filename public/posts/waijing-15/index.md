# 经气本标篇第十五


雷公问于岐伯曰：十二经气有标本乎？

岐伯曰：有之。

雷公曰：请言标本之所在。

岐伯曰：足太阳之本在跟以上五寸中，标在两络命门。足少阳之本在窍阴之间，标在窗笼之前。足少阴之本在内踝下三寸中，标在背腧。足厥阴之奉在行间上五寸所，标在背腧。足阳明之本在厉兑，标在人迎，颊挟颃颡。足太阴之本在中封前上四寸中，标在舌本乎。太阳之本在外踝之后，标在命门之上一寸。手少阳之本在小指次指之间上二寸，标在耳后上角下外眦。手阳明之本在肘骨中上至别阳，标在颜下合钳上。手太阴之本在寸口中，标在腋内动脉。手少阴之本在锐骨之端，标在背腧。手心主之本在掌后两筋之间二寸中，标在腋下三寸。此标本之所在也。

雷公曰：标本皆可刺乎？

岐伯曰：气之标本皆不可刺也。

雷公曰：其不可剌，何也？

岐伯曰：气各有冲，冲不可刺也。

雷公曰：请言气冲。

岐伯曰：胃气有冲，腹气有冲，头气有冲，胫气有冲，皆不可剌也。

雷公曰：头之冲何所乎？

岐伯曰：头之冲，脑也。

雷公曰：胸之冲何所乎？

岐伯曰：胸之冲，膺与背腧也。喻亦不可剌也。

雷公曰：腹之冲何所乎？

岐伯曰：腹之冲，背腧与冲脉及左右之动脉也。

雷公曰：胫之冲何所乎？

岐伯曰：胫之冲，即脐之气街及承山踝上以下。此皆不可刺也。

雷公曰：不可刺止此乎？

岐伯曰：大气之抟而不行者，积于胸中，藏于气海，出于肺，循咽喉，呼吸而出入也。是气海犹气街也，应天地之大数，出三入一，皆不可剌也。

陈远公曰：十二经气各有标本，各不可剌。不可刺者，以冲脉之不可剌也。不知冲脉即不知刺法也。

> 雷公请问岐伯说：十二经的气有标本吗？

> 岐伯说：有啊。

> 雷公问：请说明标气和本气所在之处。

> 岐伯说：足太阳膀胱经的本气在足跟以上面五寸中，标气在两络的命门穴；足少阳胆经的本气在足窍阴穴，标气在窗笼穴之前；足少阴肾经的本气在内踝下三寸中，标气在背腧穴；足厥阴肝经的本气在行间上五寸之处，标气在背腧穴；足阳明胃经的本气在厉兑穴，标气在咽喉的人迎穴；足太阴脾经的本气在中封穴前上四寸中，标气在舌根；手太阳小肠经的本气在足外踝的后面，标气在命门穴上一寸；手少阳三焦经的本气在小指与第四指之间上面二寸，标气在耳后上角往下的外眥穴；手阳明大肠经的本气在肘骨中往上的别阳穴，标气在面部下的合钳上；手太阴肺经的本气在寸口中，标气在腋窝内的动脉；手少阴心经的本气在掌后锐骨的末端，标气在背腧穴；手少厥阴心包经的本气在掌后两筋之间二寸中，标气在腋下三寸，这是标气和本气所在之处。

> 雷公问：标气和本气都可以使用针刺吗？

> 岐伯说：标气和本气，都不能用针刺。

> 雷公问：为什么不能用针刺呢？

> 岐伯说：标气和本气分别存在气冲，气冲不能用针刺。

> 雷公问：请说明气冲。

> 岐伯说：胃气有冲，腹气有冲，头气有冲，胫气有冲，都不能用针刺。

> 雷公问：头部的气冲在什么地方？

> 岐伯说：头部的气冲是脑。

> 雷公问：胸部的气冲在什么地方？

> 岐伯说：胸部的气冲，在胸膺和背腧，背腧穴也不能刺。

> 雷公问：腹部的气冲在什么地方？

> 岐伯说：腹部的气冲，在背腧穴、冲脉以及左右的动脉。

> 雷公问：足胫的气冲在什么地方？

> 岐伯说：足胫的气冲，在脐部的气街以及从承山穴到足后跟，这些部位都不能使用针刺。

> 雷公问：不能针刺的只有这些吗？

> 岐伯说：大气可以聚集起来暂时不行走，积累在胸中，隐藏在气海，从肺部出来，沿着咽喉呼吸而进出，因此气海正像气街一样，对应于天地的大数，出气三，入气一，都不能用针刺。

> 陈远公说：十二经的气，分别有标气和本气，不能使用针刺。之所以不能用刺，是因为冲脉不能刺。不知道冲脉，即是不知道刺法。

### 一、 十二经气的“本”与“标”定位
岐伯详细指出了各经脉之气起源（本）与显现（标）的部位。这里的“本”多在四肢远端，“标”多在头面躯干，与《灵枢·卫气》中的论述相近。

| 经脉名称 | “本”所在（起源） | “标”所在（显现/终结） |
| :--- | :--- | :--- |
| **足太阳** | 跟骨上五寸中 | 两眼（命门之络） |
| **足少阳** | 足窍阴穴之间 | 耳前窗笼（听宫/耳门附近） |
| **足少阴** | 内踝下三寸中（交信/复溜处） | 背俞穴（肾俞） |
| **足厥阴** | 行间穴上五寸处 | 背俞穴（肝俞） |
| **足阳明** | 厉兑穴 | 人迎穴、颊部、颃颡（喉咙上部） |
| **足太阴** | 中封穴前上四寸中（三阴交附近） | 舌本（舌根） |
| **太阳** (注1) | 外踝之后（昆仑附近） | 命门（目）上一寸 |
| **手少阳** | 小指次指之间上二寸（中渚/液门） | 耳后上角、外眼角（外眦） |
| **手阳明** | 肘骨中至别阳（曲池附近） | 颜面下方、合钳上 |
| **手太阴** | 寸口中（太渊/经渠） | 腋内动脉（中府/天府） |
| **手少阴** | 锐骨之端（神门） | 背俞穴（心俞） |
| **手心主** | 掌后两筋间二寸（内关） | 腋下三寸（天池） |

*(注1：文中此条未标明手足，但“外踝”多指足部，疑为补充说明足太阳或文本传抄有误，以此文原话为准。)*

### 二、 针刺禁忌：气冲不可刺
雷公询问这些标本是否可以针刺，岐伯给出了**否定**的回答，理由是“气各有冲”。
*   **核心原则：** 气冲（气的要冲、汇聚流动之地）不可随意针刺，否则会扰乱气机。

**四大“气冲”部位：**
1.  **头之冲：** 脑。
2.  **胸之冲：** 膺（胸前）与背俞穴。
3.  **腹之冲：** 背俞穴、冲脉、左右腹部动脉。
4.  **胫之冲：** 气街（脐下毛际处）、承山穴、踝上以下部位。

**禁刺原因：**
这些部位是气血运行的枢纽，尤其是“大气”积聚、呼吸出入的关键通道（气海、气街），对应天地之数（出三入一），不可轻易针刺干扰。

### 三、 大气与呼吸
*   **大气的运行：** “抟而不行”的大气积聚在胸中，储藏于气海，出于肺，通过咽喉进行呼吸吐纳。
*   **气海与气街：** 两者功能相通，是生命活动的动力源泉，故列为禁刺范围。

### 四、 陈远公点评
*   **强调冲脉：** 陈远公认为，文中强调“不可刺”，核心在于**冲脉**。
*   **理论核心：** 不了解冲脉的重要性，就无法掌握真正的针刺法则。因为冲脉为十二经之海，动冲脉则动全身气血，故需慎重。
