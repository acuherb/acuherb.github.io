# 脉动篇第四十四


雷公问于岐伯曰：手太阴肺，足阳明胃，足少阴肾，三经之脉常动不休者，何也？

岐伯曰：脉之常动不休者，不止肺胃肾也。

雷公曰：何以见之？

岐伯曰：四末阴阳之会者，气之大络也。四街者，气之曲径也。周流一身，昼夜环转，气无一息之止，脉无一晷之停也。肺胃肾脉独动者，胜于各脏腑耳，非三经之气独动不休也。夫气之在脉也，邪气中之也，有清气中之，有浊气中之。邪气中之也，清气中在上，浊气中在下，此皆客气也。见于脉中，决于气口。气口虚，补而实之；气口盛，泻而泄之。

雷公曰：十二经动脉之穴，可悉举之乎？

岐伯曰：手厥阴心包经，动脉在手之劳宫也。手太阴肺经，动脉在手之太渊也。手少阴心经，动脉在手之阴郄也。足太阴脾经，动脉在腹冲门也。足厥阴肝经，动脉在足之太冲也。足少阴肾经，动脉在足之太溪也。手少阳三焦经，动脉在面之和髎也。手太阳小肠经，动脉在项之天窗也。手阳明大肠经，动脉在手之阳溪也。足太阳膀胱经，动脉在足之委中也。足少阳胆经，动脉在足之悬钟也。足阳明胃经，动脉在足之冲阳也。各经时动时止，不若胃为六腑之原，肺为五脏之主，肾为十二经之海，各常动不休也。

陈士铎曰：讲脉之动处，俱有条理，非无因之文也。

> 雷公请问岐伯说：手太阴肺经、足阳明胃经、足少阴肾经，这三条经脉经常跳动不停，为什么？

> 岐伯说：经常跳动不停的经脉，不止肺、胃、肾三条。雷公说：怎样才能见识到呢？

> 岐伯说：四肢末节阴阳二气交会，是元气接续的地方。头、胸、腹、胫四个气街，是元气运行的路径。周流一身，昼夜循环转不穷，气没有一息的停止，脉没有片刻的停息。唯独肺、胃、肾的脉跳动不止，比各个脏腑的脉象要明显，并不是只有这三条经脉中的元气独自运动不停息。气在脉中运行，邪气会侵害它，清气会侵害它，浊气也会侵害它。邪气侵害经脉，清邪侵害身体的上部，浊邪侵害身体的下部，这都是外来的客邪之气。伤害的情况呈现在经脉中，决断于气口。气口脉虚弱，通过补益来充实；气口脉旺盛，通过泻泄来削弱。

> 雷公说：十二经动脉的穴位，可以列举出来吗？

> 岐伯说：手厥阴心包经，动脉在手心的劳宫穴。手太阴肺经，动脉在手腕的太渊穴。手少阴心经，动脉在手腕内侧的阴郄穴。足太阴脾经，动脉在小腹部的冲门穴。足厥阴肝经，动脉在足背部的太冲穴。足少阴肾经，动脉在足内踝上的太溪穴。手少阳三焦经，动脉在面部的和髎穴。手太阳小肠经，动脉在项部的天窗穴。手阳明大肠经，动脉在手腕背面的阳溪穴。足太阳膀胱经，动脉在足腘部的委中穴。足少阳胆经，动脉在小腿外侧的悬钟穴。足阳明胃经，动脉在足背的冲阳穴。各条经脉有时跳动有时停息，不像阳明胃经作为六腑的源泉、太阴肺经作为五脏的主宰、少阴肾经作为十二经的海洋那样，经常跳动而不停息。

> 陈士铎曰：讲脉跳动之处，都很有条理，不是没有原因的文章。

### 一、 脉动不休的原理
*   **普遍性**：雷公疑惑为何只有肺、胃、肾三经常动不休。岐伯纠正说，**所有经脉都是常动不休的**。
    *   **机理**：气在全身“四末”（肢体末端）与“四街”（气血通道）中周流，昼夜环转，无一息停止，所以脉搏也无一刻停止。
*   **特殊性**：为何唯独肺、胃、肾三经搏动明显（“独动”）？
    *   这是因为这三经的气血功能**胜于（强于）**其他脏腑，所以搏动感应明显，而非其他经脉不动。

### 二、 诊脉原则（气口）
*   **客气干扰**：脉中会有邪气（客气）侵入。
    *   清气中于上，浊气中于下。
*   **决断于气口**：无论邪气如何，最终的诊断决断于“**气口**”（手太阴肺经脉口）。
    *   气口虚 $\rightarrow$ 补而实之。
    *   气口盛 $\rightarrow$ 泻而泄之。

### 三、 十二经脉动脉穴位一览
岐伯详细列举了十二经脉各自的“动脉”所在之处（即可以触摸到脉搏跳动的穴位）：

| :--- | :--- | :--- |
| **手厥阴心包经** | **劳宫** | 手掌心 |
| **手太阴肺经** | **太渊** | 手腕桡侧 |
| **手少阴心经** | **阴郄** | 手腕尺侧 |
| **足太阴脾经** | **冲门** | 腹股沟部 |
| **足厥阴肝经** | **太冲** | 足背 |
| **足少阴肾经** | **太溪** | 足内踝后 |
| **手少阳三焦经** | **和髎** | 面部耳前 |
| **手太阳小肠经** | **天窗** | 颈部 |
| **手阳明大肠经** | **阳溪** | 手腕背侧 |
| **足太阳膀胱经** | **委中** | 腘窝（膝后） |
| **足少阳胆经** | **悬钟**（绝骨） | 小腿外侧 |
| **足阳明胃经** | **冲阳** | 足背最高处 |

### 四、 为何“肺胃肾”地位独尊？
虽然十二经都有动脉，但其他经脉往往“时动时止”（搏动微弱或不明显），不如以下三经**常动不休**：
1.  **胃（足阳明）**：为**六腑之原**（后天之本，气血生化之源）。
2.  **肺（手太阴）**：为**五脏之主**（主一身之气，朝百脉）。
3.  **肾（足少阴）**：为**十二经之海**（先天之本，藏精之所）。

### 五、 总结与评价
*   **陈士铎按语**：认为本篇关于脉动之处的讲解非常有条理，明确了各经脉气血显现的关键部位。

---
**简练总结：**
此篇论述了经脉搏动的规律。
1.  **原理**：气血周流不息，故十二经脉皆动。
2.  **分布**：详细列出了十二经脉各自的动脉穴位（如太渊、冲阳、太溪等）。
3.  **核心**：强调**肺、胃、肾**三经因分别作为五脏之主、六腑之原、十二经之海，其气血最盛，故搏动最明显且持久，是诊断的重点。
